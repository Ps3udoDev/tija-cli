# Reference material

Material de origen usado para diseñar Tija. Se conserva como referencia; la fuente de verdad del diseño está en [`../superpowers/specs/`](../superpowers/specs/).

| Carpeta | Contenido |
|---|---|
| [`product/`](product/) | `technical-product-draft.md`: borrador técnico y de producto original (visión, stack, roadmap, naming, dirección visual) |
| [`brand/`](brand/) | `brand-exploration-terminal.png`: exploración de marca: mascota, paleta, estados de la TUI, sprites pixel y startup screen |
| [`pull-requests/`](pull-requests/) | Estándar de PR del equipo: template, guía para agentes y la GitHub Action `pr-governance.yml` que lo valida. Son la base de los defaults de `tija init` y de la validación local de `tija pr` |
